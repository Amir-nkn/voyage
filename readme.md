Description:
Club de voyage est un site web dynamique développé avec WordPress, permettant de présenter des destinations de voyage sous forme d’articles organisés par catégories. Le site utilise des shortcodes personnalisés, un système de navigation fluide, l’intégration du Customizer WordPress, et un design entièrement responsive avec SCSS basé sur la méthodologie BEM. Il propose également une page 404 interactive, un moteur de recherche, et un affichage moderne des contenus.
